Adjust measurement noise on both axes (σx, σy), the true slope, and the X scale multiplier (k) to observe OLS attenuation bias, 90° orthogonal TLS projections, variable-order symmetry, and scale sensitivity in real time.

X축과 Y축의 측정 노이즈(σx, σy), 참 기울기, X 스케일 배율(k)을 직접 조절하며 OLS 감쇠 편향, TLS의 90° 직교 투영, 변수 순서 대칭성, 스케일 민감도를 실시간으로 확인합니다.

How to use

  1. Measurement noise: Increase σx while holding σy fixed to see the OLS line flatten toward zero (attenuation bias) while the TLS slope remains centered near the true slope when σx = σy.
  2. Variable symmetry: Toggle “Show reverse OLS” to compare y ~ x against inverted x ~ y; TLS gives the single line matching both directions.
  3. X scale sensitivity: Drag k above 1 to push TLS toward forward OLS (y ~ x), or below 1 to pull it toward reverse OLS (x ~ y).

Definitions

MethodObjective & Estimator
OLS (y ~ x)Minimizes vertical residuals Σ(yi − (a·xi + b))²; slope = Sxy / Sxx
TLS (Orthogonal)Minimizes perpendicular distances Σ(a·xi + b − yi)² / (a² + 1) via the smallest right singular vector of centered [x̃, ỹ]
Scaled TLS (x′ = k·x)Fits TLS on (k·x, y) and rescales slope back by k; approaches reverse OLS as k → 0 and forward OLS as k → ∞

사용 방법

  1. 측정 노이즈 조절: σx를 키우면 OLS 기울기가 참 기울기보다 0 쪽으로 꺾이는 감쇠 편향을 확인할 수 있습니다. 등방성 노이즈(σx = σy) 조건에서는 TLS가 참 기울기 주변을 유지합니다.
  2. 변수 순서 대칭성: ‘역방향 OLS 표시’를 켜면 y ~ x와 x ~ y 역변환 직선이 갈라지는 반면 TLS는 하나로 일치하는 모습을 비교할 수 있습니다.
  3. X 스케일 배율 (k): k를 1보다 크게 키우면 TLS가 정방향 OLS로, 1보다 작게 줄이면 역방향 OLS로 수렴합니다.

계산 기준

추정법최소화 목적함수 및 계산식
OLS (y ~ x)수직 잔차 제곱합 Σ(yi − (a·xi + b))² 최소화, 기울기 = Sxy / Sxx
TLS (직교 회귀)직선까지의 수직 거리 제곱합 Σ(a·xi + b − yi)² / (a² + 1) 최소화, 중심화 행렬 [x̃, ỹ]의 최소 특이벡터로 산출
스케일 적용 TLS (x′ = k·x)(k·x, y)에 TLS를 적합한 뒤 원단위 기울기(k·slope′)로 환산. k → 0이면 역방향 OLS, k → ∞이면 정방향 OLS로 수렴
